Project Overview

This project explores how zoning changes along Chicago’s transit corridors could affect property values, housing density, and community development outcomes through 2030 and beyond.

  • Scrape & integrate Cook County Assessor, Chicago zoning, CTA and census data
  • Model upzoning scenarios and value uplift per parcel
  • Publish interactive maps and a public-facing policy brief

Key Analysis Modules

  • Historical Appreciation — 25+ years of assessed-value trends by zone type
  • Upzoning Uplift Model — scenario-based FAR increases & value projections
  • Transit Proximity — CTA L-station proximity scoring (planned)
  • Soldier Field Tear-Down — reference-neighborhood value density projected onto Soldier Field footprint (map)
  • Equity Lens — displacement risk, anti-gentrification overlays (planned)
