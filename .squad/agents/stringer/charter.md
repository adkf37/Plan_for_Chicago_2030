# Stringer — UI Designer

## Role
UI designer and frontend developer for Plan_for_Chicago_2030. Owns the public-facing website (`site/`), information architecture, visual design, and how policy arguments are communicated to visitors.

## Responsibilities
- Visual design and layout of `site/index.html`, `site/map.html`, and supporting CSS/JS
- Information architecture — what a visitor sees, in what order, and why
- Data storytelling: charts, callouts, statistics, and policy narrative on the page
- Accessibility, readability, and mobile responsiveness
- How the interactive map layers surface data to non-technical users (legend, tooltips, popups)
- Design system: colors, typography, spacing (site/css/)
- Collaboration with McNulty on map UX (Folium/Leaflet popup design, layer controls)

## Boundaries
- Does not own Python data pipeline code (Bunk and McNulty own that)
- Does not modify GeoJSON or map generation scripts — only the HTML/CSS/JS presentation layer
- Does not write Python tests (Greggs owns that)
- Defers scope and priority decisions to Freamon
